# workforce-intelligence-retention-analytics
The Workforce Intelligence & Retention Analysis project is an Excel-based HR analytics project designed to analyze employee demographics, workforce distribution, compensation, hiring trends, employee performance, and retention patterns.


## Project Overview

The **Workforce Intelligence & Retention Analysis** project is an Excel-based HR analytics project designed to analyze employee demographics, workforce distribution, compensation, hiring trends, employee performance, and retention patterns.

The project uses employee-level HR data to transform raw information into meaningful insights through data cleaning, analysis, summary tables, and an interactive-style Excel dashboard.

The dashboard provides an overview of workforce composition and helps identify patterns related to employee retention, departmental distribution, compensation, and performance.

## Project Objectives

The key objectives of this project are:

- Analyze overall workforce distribution across departments.
- Understand the gender distribution within each department.
- Evaluate average annual Cost to Company (CTC) across departments.
- Analyze employee retention and employment status.
- Identify hiring trends based on employees' joining years.
- Examine employee performance ratings and satisfaction scores.
- Create rule-based hiring and bonus eligibility indicators.
- Present key HR metrics through an Excel dashboard.

## Dataset Overview

The workbook contains **100 employee records** across 7 departments.

The dataset includes the following information:

| Category | Attributes |
|---|---|
| Employee Information | Employee ID, Name, Gender, Date of Birth |
| Employment Details | Date of Joining, Year of Joining, Designation, Experience |
| Organizational Details | Department, Reporting Manager |
| Compensation | Annual CTC |
| Employment Status | Active, On Notice, Resigned |
| Performance Metrics | Performance Rating, Satisfaction Score |
| HR Indicators | Hiring Prediction, Bonus Eligibility |

The workbook also contains employee contact and payroll-related fields used in the underlying employee records.

## Workbook Structure

The project consists of the following worksheets:

| Worksheet | Description |
|---|---|
| Raw data | Contains the original employee dataset with 100 records. |
| Clean_Emp_data | Contains prepared employee data, joining year, and additional HR classification fields. |
| Dept.wise Gender ratio | Presents department-wise male and female employee distribution. |
| CTC Analysis | Compares average annual CTC across different departments. |
| Retention Analysis | Analyzes Active, On Notice, and Resigned employees department-wise. |
| Status of employment | Provides an overall breakdown of employee employment status. |
| Hiring Trend | Shows the number of employees hired each year from 2019 to 2025. |
| Cards | Provides department-wise headcount, average CTC, and average employee experience. |
| Performance & Satisfaction Indx | Contains performance ratings and satisfaction scores for analysis. |
| DashBoard | Provides a visual summary of important workforce and HR metrics. |
